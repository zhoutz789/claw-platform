>
> **本轮（v3）已落实 5 项确认决策**：① 三级钻取路径合适（模板→产品→设备→详情）；② 客运本期做 3 个子模块（打的 / 公交 / 顺风车，货运归入物流）；③ 产权"当前价值"由系统按 10% 年利率核算；④ 租赁实时轨迹不隐藏、历史轨迹仅本人使用期可见；⑤ 多语言仍暂缓。

## 一、归属层级（核心修正）

```
平台 · 产品模板（类，通用结构，无品牌方）
   └─▶ 品牌方 · 产品（调用模板创建，统领设备，归属唯一品牌方）
          └─▶ 设备（对象，仅属 一个产品 + 一个品牌方）
```

- 产品模板**不再带品牌方**（已移除「归属品牌方」字段）；品牌方在「产品」中调用模板创建自有产品。
- 设备只属于一个产品和一个品牌方；点击产品模板行→看字段定义+派生品牌产品；点击产品→看其下所有设备+共用字段；点击设备→设备详情。
- 商品发布改为选择品牌「产品类（多选）」，一类产品管全部设备，产品端闭环。

## 三、关键布局决策

- **三级钻取**：模板→产品→设备，逐层点击进入，设备详情为最丰富页。（已确认路径合适）
- **设备详情能力矩阵**：客运本期落地 **打的 / 公交 / 顺风车 3 个子模块**（货运归入物流），录像脱敏回传，每条收益模块独立「任务大厅」入口。
- **共享赋权 / 轨迹权限**（已确认）：产权人可授予/收回功能权限；租赁场景默认最小权限：
  - 实时定位 → 承租人**可见（不隐藏）**；
  - 历史轨迹 → 仅显示承租人**本人使用期间**产生的部分，其余历史对承租人隐藏；
  - 收益 / 产权 / 他人历史轨迹 → 默认隐藏。
- **任务发布独立成菜单**，与产品/商品并列；附近车辆覆盖客运三类（公交·打的·顺风车）+ 货运。
- **绑定-产权-租赁**三态合一：扫码绑定一次、再绑走产权转移（系统核算当前价值 + 平台托管资金 + 自动过户，复用三专户）、租赁走受限权限模板。

## 四、已采纳的优化建议（转代码落地）

> 周老板 2026-08-25 第四轮全部采纳，并新增第 7 项。以下 7 项均为转代码依据。

1. **产权转移复用三专户托管**：过户走「托管资金+自动过户」（ABA 三专户·资金隔离），比私下交易更安全，也便于风控与税务。
2. **租赁权限模板化（最小权限）**：把"产权人勾选可授予功能"沉淀为权限模板（「仅使用」「使用+定位」「全权」），减少每次勾选成本，也利于审计。
3. **任务大厅统一能力标签调度**：给每台设备打"能力标签"（物流/客运/广告/录像），任务按标签+地理位置匹配附近设备，降低空驶、提升接单率。
4. **合格证二维码签名防篡改**：二维码内嵌设备唯一编号+平台签名，扫码即验真，杜绝套牌/假合格证。
5. **数据闭环建议**：设备详情页统一作为"资产数字孪生"入口，所有功能（收益/任务/维修/转让）围绕设备 ID 聚合，前端只需按角色/权限过滤字段，避免各模块重复拉取。
6. **产权现值公式可配置**：当前按 10% 年利率复利（购入原值 × (1+10%)^持有年数）核算；已将利率与计息方式（复利/单利）设为**系统参数**（系统设置→资产参数），可按资产类型差异化。
7. **品牌归属名下公司 + 商标证书验证（新增）**：品牌挂在用户个人或名下公司下，自动套用公司注册资料；创建品牌须提交**商标注册证书**，平台验证（OCR+人工）通过方可使用；**无品牌方 / 未验证品牌的产品禁止发布**。公司+商标证书归档留存，以备责任落实与合法沟通，也方便以后分组管理。
